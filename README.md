SlangBot - Бот для расшифровки сленга 🤖🔍
Telegram-бот, который помогает понять современный молодежный сленг, используя GigaChat API и пользовательский словарь.

👉 Попробовать бота: @YourBotName (ссылка будет после деплоя)

🔹 Возможности
✅ Поиск значений сленговых слов через GigaChat API
✅ Добавление своих слов в локальный словарь (/add слово значение)
✅ Краткие и понятные объяснения с примерами использования
✅ Поддержка Replit для бесплатного хостинга

🔹 Как запустить бота?
1️⃣ Вариант 1: Запуск на Replit (бесплатно)
Скопируйте код из bot.py в новый Python-проект на Replit

Добавьте токены прямо в код (или используйте Secrets для безопасности)

Создайте файл .replit с содержимым:

toml
run = "python slangy.py"
Нажмите "Run" — бот запустится автоматически!

(Replit может останавливать бота при бездействии. Для поддержания работы используйте UptimeRobot.)

2️⃣ Вариант 2: Локальный запуск (на ПК/VPS)
Установите зависимости:

Скачайте файл с гитхаба
Запустите бота:

bash
python slangy.py
Бот будет работать в фоне (для VPS используйте tmux или systemd).

🔹 Команды бота
Команда	Описание	Пример
/start	Приветствие	/start
/add	Добавить слово	/add кринж стыдно смотреть
Любое слово	Поиск значения	"что значит краш"
🔹 Технологии
Python 3.10+

python-telegram-bot (для Telegram API)

GigaChat API (для обработки сленга)

Flask (для поддержания работы на Replit)

JSON (локальное хранение слов)

🔹 Важно!
⚠️ Токены в коде — небезопасно!

Для реального использования лучше хранить их в Secrets (Replit) или .env.

⚠️ GigaChat имеет лимиты

Бесплатный тариф ограничен, возможны ошибки при превышении лимита.
